Collector's methods
joining()	    Concatenate strings

Variations of joining      //input = ("A", "B", "C");
Type	                   Example Code	                Example Output
No delimiter	           .joining()	                 ABC
With delimiter	           .joining(",")	             A,B,C
Delimiter + Prefix/Suffix	.joining(",", "[", "]")	     [A,B,C]
