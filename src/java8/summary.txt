
------------ Test 01 Recap ------------
toList()	.collect(Collectors.toList())	Collects elements into a List
toSet() 	.collect(Collectors.toSet())	Collects elements into a Set
toMap() 	.collect(Collectors.toMap(k,v))	Collects elements into a Map
groupingBy()	.collect(Collectors.groupingBy(k))	Groups elements by key

------------ Test 02 Recap ------------
Collector's methods
joining()	    Concatenate strings
counting()  	Count elements
summingInt()	Sum of integer properties
averagingInt()	Average of integer properties

Variations of joining      //input = ("A", "B", "C");
Type	                   Example Code	                Example Output
No delimiter	           .joining()	                 ABC
With delimiter	           .joining(",")	             A,B,C
Delimiter + Prefix/Suffix	.joining(",", "[", "]")	     [A,B,C]

------------ Test 03 Recap ------------
Feature          ->    	 Description
groupingBy(f)	 ->      Groups stream elements by a function f
groupingBy(f, counting())  -> 	Groups and counts elements
groupingBy(f, mapping(g, toList()))	  ->  Groups and transforms
groupingBy(f, groupingBy(g))          ->  Nested grouping

mapping(f, toList())	      ->  Transforms a stream of elements into another type

------------ Test 04 Recap ------------
partitioningBy() methods of Collectors.

partitioningBy(Predicate)	    ->      Simple partition into two lists	  || Return Type > Map<Boolean, List<T>>
partitioningBy(Predicate, Collector) -> Partition and apply downstream collector || Return Type > Map<Boolean, D>

summarizingInt()	->	Return Type > IntSummaryStatistics
summarizingLong()	->	Return Type > LongSummaryStatistics
summarizingDouble()	->	Return Type > DoubleSummaryStatistics

All three classes (IntSummaryStatistics, LongSummaryStatistics, DoubleSummaryStatistics) provide:
Method	    -> Description
getCount()	-> Number of elements processed
getSum()	-> Sum of values
getMin()	-> Minimum value
getMax()	-> Maximum value
getAverage()	-> Average of values (returns double)
